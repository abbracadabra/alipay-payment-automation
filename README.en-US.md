

**Automate Web-based Alipay Payments: Using Selenium to Simulate Browser for Automatic Order Payment**

Before running, you need to install:
- Java 1.8
- Maven
- Latest Google Chrome browser (Chrome v70-72)
- Modify line 6 of PTest.java to fill in your Alipay account, login password, and payment password
- Modify line 7 of PTest.java to fill in the merchant's payment form

Tested on the following platforms:
- Windows 10 64-bit
- Ubuntu 16.04 64-bit
- CentOS 7 64-bit

Usage:
```
cd alipay-payment-automation
mvn test
```
